Help improve the tracker

No account required. Crowd reports are compared with the reading at submission time and reviewed before use in forecasts.

Feedback is private to the project administrator. No name is required. A random browser token limits repeat submissions. Contact details are stored separately and used only for follow-up. Please avoid identifying other climbers.

About The Knot crowd tracker

When is The Knot open?

Regular hours in Gainesville: Monday–Friday 7 AM–11 PM; Saturday–Sunday 7 AM–10 PM Eastern. Check official closures and changes before visiting.

Why can the live count be higher than the actual crowd?

The reported count appears to rise with check-ins and is periodically corrected. Downward changes are inferred recounts, not independently confirmed headcounts. An experimental estimate is shown only when recent recount evidence is available.

What is the best time to climb?

Use the visit planner for a full session or Weekly Trends for typical reported crowds by weekday and hour. Forecasts are estimates, not guarantees.

Install the tracker on your phone or Mac.

Check how busy The Knot Climbing Gym in Gainesville is before heading over. The live count comes from the gym's public occupancy reading. Staff recounts periodically correct the count, while future crowds are estimates based on previous observations. Predictions can change as new data arrives.

This is an independent project, not the gym's official website. For hours, rates, events, and gym announcements, visit The Knot's official website.
