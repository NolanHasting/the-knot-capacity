Get the Knot Capacity widget

Check the reported crowd at The Knot Climbing Gym in Gainesville, Florida, before heading over.

iPhone home screen widget

Use the free Scriptable app for a small widget showing the latest available count.

  1. Install Scriptable and create a new script.
  2. Download the widget script, or use Copy script below and paste into Scriptable.
  3. Name the script Knot Capacity and run it once.
  4. On your home screen, add a small Scriptable widget. Edit Widget and select Knot Capacity.
  5. Tap the widget to open the full tracker.

The widget shows the time of its latest reading.

iPhone or iPad shortcut

Open the tracker in Safari, tap Share, then Add to Home Screen.

Android shortcut

Open the tracker in Chrome, open the menu and choose Add to Home screen or Install, if offered. This is a shortcut rather than a native live widget.

Mac

Open the tracker in Safari and choose File → Add to Dock (macOS Sonoma or newer). On supported Macs, you can also add the iPhone Scriptable widget through macOS widget settings.
